# Execil

Landing page for [execil.net](https://execil.net) — a medical billing and revenue
cycle management service for independent US practices.

![The Execil landing page](docs/screenshots/execil-net.jpg)

One page and three legal pages, prerendered to static HTML and served from
Cloudflare Workers. The assessment form is the only dynamic part: it posts to a
Worker route that verifies a Turnstile token and sends the submission on through
Resend. Nothing is stored.

## Running it

```bash
pnpm install
pnpm dev          # http://localhost:3000
```

| command             | what it does                                          |
| ------------------- | ----------------------------------------------------- |
| `pnpm dev`          | dev server on port 3000                               |
| `pnpm build`        | regenerates `llms.txt`, then builds and prerenders    |
| `pnpm check`        | format, lint and types in one pass (`--fix` to apply) |
| `pnpm placeholders` | lists bracketed copy still awaiting real values       |

Copy `.env.example` to `.env` and `.dev.vars.example` to `.dev.vars` first. The
two are different things: `VITE_` values are build-time and get baked into the
client, while `.dev.vars` holds the Worker's runtime secrets.

## Layout

```
src/
  routes/      one file per URL; owns that page's <head> and structured data
  sections/    the page's blocks — Hero, Services, Faq, …
  base/        wrappers around raw elements; everything else composes these
  styles/      StyleX tokens and the theme
  messages.json  every user-facing string on the landing page
  legal.json     the three legal documents, kept apart so they bundle separately
  seo.ts         canonical URLs and the schema.org graph
public/
  brand/       the wordmark and social assets — see public/brand/README.md
  llms.txt     generated by scripts/llms-txt.mjs; do not edit by hand
scripts/       brand rasterisers and the generated-file writers
docs/          ADRs, research notes and the design canvas
```

Imports run one way: `routes/ → sections/ → base/ → styles/`. Sections compose
base components and never each other.

## Conventions

`CLAUDE.md` has the four that lint cannot enforce and that get checked in
review — tokens rather than literal values, roles rather than palette ramps,
`style` that positions but never restyles, and user-facing attribute strings
coming from `messages.json`. `CONTEXT.md` is the domain glossary; decisions live
in `docs/adr/`.

## Deployment

Cloudflare Workers Builds, connected to this repo. `main` is production at
execil.net; work happens on `dev`, which gets its own preview URL. There is no
deploy workflow in CI — `ci.yml` runs format, lint, types, build and the
placeholder report only.

`docs/provisioning.md` is the runbook, but it is derivative: where it disagrees
with Cloudflare's or a vendor's own docs, they win.
